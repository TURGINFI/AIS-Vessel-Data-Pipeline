# AI Assistance Disclosure

This repository is an AI-assisted project.

The source code, documentation, Docker configuration, API documentation, frontend text, and configuration examples were generated with AI assistance. Human contributors defined the goal, reviewed AI-generated suggestions, chose among the proposed approaches, requested revisions, and made final project decisions.

Human involvement was primarily decision-making and review. The AI assistant performed the implementation work under human direction.

This disclosure applies to the whole project unless a future file explicitly states otherwise.
