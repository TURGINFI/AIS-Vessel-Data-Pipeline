# AI Assistance Disclosure

This repository is an AI-assisted project.

Almost all source code, documentation, Docker configuration, API documentation, frontend text, tests, and configuration examples were generated with AI assistance. Human contributors designed the project structure, defined the goal, reviewed AI-generated suggestions, chose among the proposed approaches, requested revisions, and made final project decisions.

This is the second implementation of the project. The first version was completed manually, and this version was rebuilt with AI assistance to compare robustness, maintainability, and implementation quality against the manual implementation.

Human involvement was primarily structure design, decision-making, and review. The AI assistant performed the implementation work under human direction.

AI tools used:

- OpenAI Codex / ChatGPT GPT-5 coding agent for code generation, debugging, documentation, test updates, and repository maintenance.

This disclosure applies to the whole project unless a future file explicitly states otherwise.
